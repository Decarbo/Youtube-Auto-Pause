This README provides step-by-step instructions on how to install a local browser extension in Google Chrome, Mozilla Firefox, and Microsoft Edge. Follow the instructions for your specific browser to get started.

## Prerequisites

-  Ensure you have the latest version of your browser installed.
-  You should have the extension files available on your local machine, typically in a folder containing a `manifest.json` file and other necessary files.

## Installing a Local Extension in Google Chrome

1. **Open Chrome**: Launch the Google Chrome browser.
2. **Access Extensions Page**: Click on the three vertical dots in the upper right corner, go to `More tools`, and select `Extensions`. Alternatively, you can type `chrome://extensions/` in the address bar and press Enter.
3. **Enable Developer Mode**: Toggle the switch for `Developer mode` in the upper right corner of the Extensions page.
4. **Load Unpacked Extension**: Click on the `Load unpacked` button. A file dialog will open.
5. **Select Extension Folder**: Navigate to the folder where your extension files are located and select it. Click `Select Folder`.
6. **Extension Installed**: Your extension should now be installed and visible on the Extensions page. You can enable or disable it as needed.

## Installing a Local Extension in Mozilla Firefox

1. **Open Firefox**: Launch the Mozilla Firefox browser.
2. **Access Add-ons Manager**: Click on the three horizontal lines in the upper right corner, then select `Add-ons and themes`. Alternatively, you can type `about:addons` in the address bar and press Enter.
3. **Enable Debugging**: Click on the gear icon in the upper right corner and select `Debug Add-ons`.
4. **Load Temporary Add-on**: Click on the `Load Temporary Add-on` button. A file dialog will open.
5. **Select Manifest File**: Navigate to the folder where your extension files are located and select the `manifest.json` file. Click `Open`.
6. **Extension Installed**: Your extension should now be installed temporarily. Note that it will be removed when you restart Firefox.

## Installing a Local Extension in Microsoft Edge

1. **Open Edge**: Launch the Microsoft Edge browser.
2. **Access Extensions Page**: Click on the three horizontal dots in the upper right corner, go to `Extensions`, or type `edge://extensions/` in the address bar and press Enter.
3. **Enable Developer Mode**: Toggle the switch for `Developer mode` in the lower left corner of the Extensions page.
4. **Load Unpacked Extension**: Click on the `Load unpacked` button. A file dialog will open.
5. **Select Extension Folder**: Navigate to the folder where your extension files are located and select it. Click `Select Folder`.
6. **Extension Installed**: Your extension should now be installed and visible on the Extensions page.

## Troubleshooting

-  **Extension Not Loading**: Ensure that the `manifest.json` file is present and correctly formatted.
-  **Permissions Issues**: Check if the extension requires specific permissions that need to be granted.
-  **Browser Compatibility**: Make sure the extension is compatible with your browser version.
